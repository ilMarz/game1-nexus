# Sword clash recordings

Author: [StarNinjas](https://opengameart.org/users/starninjas).
Source: [20 Sword Sound Effects (Attacks and Clashes)](https://opengameart.org/content/20-sword-sound-effects-attacks-and-clashes).
License: [Creative Commons Zero / CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
Downloaded: 2026-10-25.
Archive: https://opengameart.org/sites/default/files/sword_clash_-_starninjas_0.zip

The source page identifies these as recorded metal clashes/blocks, made by
moving two knives against each other and editing the recordings in Audacity.

Bundled files are the original, unmodified Ogg Vorbis recordings, renamed:

| Bundled file | Original file |
| --- | --- |
| sword-clash-1.ogg | sword_clash.1.ogg |
| sword-clash-3.ogg | sword_clash.3.ogg |
| sword-clash-5.ogg | sword_clash.5.ogg |

The mixer varies pitch slightly during playback and uses these three recordings
for melee impact events from both armies. There are no runtime requests to an
external audio service. Synthesis remains available while samples load or if a
sample cannot be fetched/decoded. Credit is appreciated by the author and is
provided here, although CC0 does not require attribution.
